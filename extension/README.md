# טלם+ (Telem Plus)

תוסף לכרום שמלביש ממשק חדש על **telem.tel-aviv.gov.il**.
הוא משנה רק את המראה. הוא לא ממלא שדות, לא לוחץ על "שמירה" או "שליחה", ולא שומר או שולח את תוכן הדיווחים לשום מקום.

## התקנה (פעם אחת, דקה)

1. מחלצים את קובץ ה-zip לתיקייה קבועה (למשל `Documents/telem-plus`). לא למחוק אותה אחר כך, כי כרום טוען את התוסף ממנה.
2. בכרום פותחים את הכתובת `chrome://extensions`.
3. מדליקים את **Developer mode / מצב מפתח** (מתג בפינה הימנית העליונה).
4. לוחצים **Load unpacked / טעינת תוסף לא ארוז** ובוחרים את התיקייה שחילצתם (זו שיש בה את `manifest.json`).
5. מנעצים את התוסף לסרגל (אייקון הפאזל, ואז הנעץ ליד "טלם+").
6. נכנסים לטלם, או מרעננים אם הוא כבר פתוח.

> אם המחשב מנוהל על ידי העירייה ומצב מפתח חסום, צריך לבקש מה-IT לאשר את התוסף.

## מה יש בו

- **עיצוב חדש לכל המערכת**: רקע "אורורה" עדין, כרטיסים מזכוכית, טיפוגרפיה עברית (Heebo / Rubik), שדות מעוגלים.
- **מצב כהה / בהיר / אוטומטי** (לפי הגדרות המחשב), וגם כפתור מעבר מהיר בסרגל העליון.
- **4 ערכות צבע**: ים תיכון, שקיעה, הדרים, סגול.
- **שולחן עבודה**: כרטיס פתיחה עם ברכה לפי השעה, תאריך לועזי ועברי, וכפתור "דיווח התערבות חדש". המונים מוצגים ככרטיסים עם ספירה מונפשת.
- **טופס דיווח התערבות** מחולק ל-5 שלבים ממוספרים:
  - טבעת התקדמות של שדות החובה, בסרגל פעולות שנשאר צמוד לתחתית המסך.
  - מונה מילים ותווים לסיכום הפגישה.
  - **מצב כתיבה ממוקדת**: מסך מלא ושקט לכתיבת הסיכום. יוצאים ממנו עם Esc.
  - כשבוחרים "חרום" כל הטופס מקבל הדגשה אדומה.
- **חיפוש מהיר (Ctrl+K, או ⌘K במק)**: ניווט בין עמודים, החלפת מצב תצוגה וצבעים, וכניסה למצב כתיבה.
- **כפתור כיבוי**: בחלון התוסף אפשר לחזור לעיצוב המקורי בלחיצה.

## עדכון

כשמקבלים גרסה חדשה, מחליפים את הקבצים בתיקייה ולוחצים ↻ (רענון) על התוסף ב-`chrome://extensions`.

## אם משהו נראה שבור

המערכת עשויה להשתנות. אפשר לכבות את טלם+ זמנית בחלון התוסף או דרך Ctrl+K ← "כיבוי טלם+".
